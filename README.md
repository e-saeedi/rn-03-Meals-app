# 🍔 Meals App

*[🇮🇷 برای مطالعه توضیحات فارسی کلیک کنید](#-نسخه-فارسی)*

A React Native mobile application for browsing and managing food recipes.


## ✨ Features
- Browse food categories and recipe details.
- Add favorite meals to a watchlist using React Context.
- Smooth navigation between screens using React Navigation.

## 🛠️ Tech Stack
- React Native / React Navigation
- React Context API
- JavaScript / TypeScript

## 🚀 Getting Started

1. Clone the repository:
\`\`\`bash
git clone https://github.com/e-saeedi/rn-03-Meals-app.git
\`\`\`

2. Install dependencies:
\`\`\`bash
cd rn-03-Meals-app
npm install
\`\`\`

3. Run the app:
\`\`\`bash
npm start
\`\`\`

## 🇮🇷 نسخه فارسی

یک اپلیکیشن موبایل برای مشاهده و مدیریت دستور پخت غذاها، توسعه‌یافته با React Native.


## ✨ ویژگی‌ها
- نمایش دسته‌بندی غذاها و جزئیات دستور پخت.
- امکان افزودن غذاها به لیست علاقه‌مندی‌ها با استفاده از React Context.
